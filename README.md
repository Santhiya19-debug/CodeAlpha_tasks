# Age Calculator Web Application

A responsive Age Calculator built using HTML, CSS, and JavaScript.

## Features

- Calculate age in years, months, and days
- Input validation
- Responsive design
- Light and Dark mode
- Local Storage support
- User-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- index.html
- style.css
- script.js
